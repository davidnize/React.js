# React.js

A collection of exercises and projects I'm building while learning **React.js**.

This repository documents my progress, from the fundamentals of React to working with components, props, state, events, forms, and more.

## Topics Covered

- React components and component structure
- Importing and exporting components
- Props and component communication
- Rendering lists with `map()`
- Filtering and working with arrays
- Conditional rendering
- React Hooks (`useState`)
- ES6 destructuring and spread operator
- Event handling and forms
- Managing component state and component trees

## Projects

The repository also includes small practical projects, including a **Keeper App**, where I practice building interactive user interfaces with React.

## Purpose

This is my personal learning repository. I'm using it to practise concepts, experiment with code, and improve my understanding of React through hands-on projects.
